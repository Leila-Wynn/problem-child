# The Ninth Room

Page 2: I am currently building this website for my Web Design I class. It is an interactive website based on a cat called Fig who refers to herself as the "Problem Child". This website is meant to be Fig's own little world, not a website.

Current Progress

I've been working on the main Ninth Room page and Fig's journal so far.

Objects that users can hover over, click on, and drag around the main page. Some objects will lead to another page or part of the site later.

Fig and then describes how some of the dynamic behavior of the website works through a set of rules.

Another feature of the site that is being constructed is the journal. It is a series of entries written in the perspective of Fig that describe the nature of the Ninth Room and who Fig is, as well as how to use the site.

In Progress

This site is under construction. Additional pages, links, interactivity, content, and improvements will be added as the site develops.
